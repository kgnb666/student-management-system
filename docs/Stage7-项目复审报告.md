## 4. 复审发现并已修复的问题

| 问题 | 说明 | 处理 |
| --- | --- | --- |
| 未知路径返回 500 | 全局兜底异常处理把资源未找到异常也当成服务器错误 | 增加 404/405/415 处理，实测返回 `{"code":404,"message":"接口不存在"}` |
| 启动脚本中文解析错乱 | 批处理为 UTF-8 无 BOM，cmd 解析含中文行时字节错位 | 改为 UTF-8 with BOM + CRLF，实测解析与输出正常 |
| 端口占用被误判为服务已运行 | 原脚本只探测端口是否被监听，端口被其他项目占用时会误判 | 改为探测健康检查与首页标题，占用时给出明确提示 |
| 测试自身缺陷 | 多次写入时 verify 次数不匹配；0/100 边界期望值写反；MyBatis 会话级缓存导致集成测试读到旧聚合 | 分别改为捕获最后一次调用、修正期望、显式清理缓存 |

这些问题都是通过实际执行验证发现的，已全部修复并重新验证通过。

### 5.1 功能与安全（建议优先）

| 序号 | 问题 | 说明与建议 |
| --- | --- | --- |
| 1 | 没有「修改密码」功能 | 学生/教师只能由管理员重置为 `123456`；后端已具备改密后旧 token 立即失效的基础，补前端入口与接口即可 |
| 2 | 待审核注册缺少提醒 | 自助注册后处于待审核状态，但管理员端没有未读提示，需人工翻列表，建议加角标或首页提醒 |
| 3 | 默认密码统一 | 管理员创建学生/教师仍使用 `123456`，建议首次登录强制改密 |
| 4 | 登录失败计数为单实例内存 | 服务重启或多实例部署后失效，需要跨实例共享时应换 Redis |
| 5 | 成绩只留最后修改人 | `score` 表仅有 `update_by` 与 `update_time`，没有逐次变更历史，如需审计应增加操作日志表 |
| 6 | 注册接口无频率限制 | 已有待审核机制兜底（注册后无法登录），但接口仍可被批量提交，可加 IP 限流 |
