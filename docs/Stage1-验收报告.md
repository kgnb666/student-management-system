## 12. 发现的问题

### 问题 1：教师可以给非课程名单学生录成绩

严重程度：高

原因：保存成绩时只校验了课程是否属于当前教师，没有校验学生是否在 `course_student` 名单中。

实测：教师向不属于课程 2 的学生 7 写入成绩，接口返回成功，并在 MySQL 中生成记录。

### 问题 2：使用 `127.0.0.1:5173` 登录被 CORS 拒绝

严重程度：中

原因：后端只允许 `http://localhost:5173`，浏览器使用本地 IP 地址时触发 403。

### 问题 3：中文路径下 `mvn spring-boot:run` 找不到主类

严重程度：中

原因：Spring Boot Maven 插件 fork 子进程时使用参数文件，当前中文路径在 Windows GBK 环境下出现类路径编码问题。
